# User Manual

1. Register with first name, last name, email, and a strong password.
2. Enter the OTP sent to email before logging in.
3. Admins manage users, inventory, inspections, maintenance, reports, and notifications.
4. Inspectors manage inspections and maintenance records.
5. Users view extinguisher status, schedule inspections, and read notifications.
6. Use delete buttons carefully; the frontend asks for confirmation before destructive actions.
